# isopxl Playdate example

Hello! This is a small example on how to load a spritesheet generated by isopxl (https://isopxl.app) in the Playdate handheld game system made by Panic and Teenage Engineering.

isopxl is a lowpoly 3d pixelart editor that can help you build assets for your game. It's especially useful for isometric games but even in 2d, or top-down, isopxl will help you create consistent assets from different angles.

You will need the following

1. SDK from Playdate: https://play.date/dev/
2. This source code
3. Run the command: `pdc Source CrankViewer.pdx`
4. This will create CrankViewer.pdx. You can double-click to run it in the simulator.
5. Use the crank to rotate the bird.
